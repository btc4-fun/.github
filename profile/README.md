# btc4fun

Four small projects, one idea: a paper envelope to get started — not a promise of profit.

This project is under construction and is not yet live with real customers. Nothing here guarantees profit, safety, or that a printed envelope is authentic.

- Envelope and website: a paper envelope holding a small amount of bitcoin, for gifts and as a first step.

- Offline generator: build envelopes on a computer that is not connected to the internet.

- Customer check app: look up a tag's balance and printed serial.

- Seller app: write and read tag data.
